# Notebook Walkthrough

`exploration.ipynb` is an interactive companion to `main.py`: it runs each
module in small, inspectable steps and displays the generated charts inline.

- Simulation shows how known conversion rates become observed user outcomes.
- Statistical tests show how binary and continuous metrics are evaluated.
- Power analysis shows why sample size must be planned before launch.
- Pitfall simulations show how peeking and multiple metrics create false positives.
- Simpson's paradox shows why segment context matters when reading aggregates.
- Reporting demonstrates how statistical output becomes a decision-ready narrative.
